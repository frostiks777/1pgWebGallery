# Photo Gallery

Контекст сервиса: одностраничная веб-галерея фотографий из WebDAV-облака. Владелец настраивает источник, зритель листает коллажи, открывает лайтбокс и при необходимости вводит пароль.

## Language

### Данные

**Фото**:
Изображение из источника (или демо-набора), элемент галереи.
_Avoid_: Картинка, снимок, image

**Папка**:
Директория источника; список фотографий с навигацией по хлебным крошкам.
_Avoid_: Каталог, директория, альбом (Album — это раскладка)

**Источник**:
Место хранения фото: WebDAV-сервер или встроенный демо-набор.
_Avoid_: Бэкенд, хранилище, облако

**Демо-режим**:
Режим без переменных `WEBDAV_*`: отдаются фото из `public/demo-photos/`.
_Avoid_: Тестовый режим, мок

**Обложка**:
Фото папки (до трёх), показываемое как превью папки в списке.
_Avoid_: Превью, thumbnail (миниатюра — другое)

**Скрытое фото**:
Фото, убранное владельцем из галереи; обратимо (список в dir-meta).
_Avoid_: Удалённое

**Панорама**:
Фото, помеченное как широкое, для особого отображения.
_Avoid_: Широкое фото, панорамный снимок

**Миниатюра**:
Сгенерированное WebP-изображение (размеры thumbnail/medium/full) для отдачи в UI.
_Avoid_: Превью (превью папки — обложка), эскиз

**Видео**:
Файл рядом с фото с тем же именем (stem); проигрывается нативным `<video>`, постер извлекает ffmpeg.
_Avoid_: Трейлер (удалённый подход)

### Интерфейс

**Галерея**:
Главная страница с коллажем фотографий.
_Avoid_: Главная, homepage

**Раскладка**:
Один из шести способов укладки фото: masonry, bento, honeycomb, wave, minimalism, album.
_Avoid_: Макет, layout (в коде — `CollageLayout`)

**Лайтбокс**:
Полноэкранный просмотр фото с зумом, навигацией и действиями (скрыть, удалить, обложка, панорама).
_Avoid_: Модалка, просмотрщик, viewer

**Парольная защита**:
Опциональный ввод `WEBDAV_LOGON_PASSWORD` перед доступом к галерее.
_Avoid_: Авторизация, логин

**Пакетная генерация**:
Кнопка предгенерации всех миниатюр с индикатором прогресса.
_Avoid_: Прогрев, batch

### Состояние

**`.data/`**:
Локальное состояние приложения: миниатюры и `dir-meta` (скрытые, панорамы, обложки). Не кэш: стирание сбрасывает настройки владельца.
_Avoid_: Кэш, temp

**dir-meta**:
JSON-файл на папку с тремя списками: `hidden`, `panoramas`, `covers`.
_Avoid_: Метаданные, настройки папки

**Со-локационный кэш**:
Миниатюры в `.thumbs/` рядом с фото в WebDAV (`WEBDAV_COLOCATED_CACHE`).
_Avoid_: Серверный кэш
